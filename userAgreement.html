Пользовательское соглашение.

1. Определения

  • 1.1. API — RESTful интерфейс для получения JSON‑данных по HTTP/HTTPS.;
  • 1.2. Пользователь — физическое или юридическое лицо, получившее доступ к API;
  • 1.3. Токен Доступа (на англ: accessToken) — уникальный идентификатор, предоставляемый Пользователю для аутентификации запросов;
  • 1.4. Запрос — HTTP‑запрос к эндпоинтам API;
  • 1.5. Данные — информация в формате JSON, возвращаемая API в ответ на запрос;

2. Предмет соглашения

2.1. Настоящее Пользовательское соглашение (далее — «Соглашение») регулирует условия использования RESTful API сервиса по адресу wantedjson.ru (далее — «Сервис») для получения данных в формате JSON. Использование Сервиса означает полное и безоговорочное принятие условий Соглашения.

3. Регистрация и авторизация

3.1. Для доступа к API Пользователь обязан пройти регистрацию на странице Сервиса wantedjson.ru/signup.html и получить уникальный токен доступа (далее токен). Прохождение пользователем процедуры регистрации и получения токена на Сервисе автоматически означает - полное и безоговорочное принятие условий Соглашения

3.2. Токен должен передаваться в заголовке каждого запроса: "Authorization": 'Bearer<ваш токен>'.

3.3. Пользователь несёт полную ответственность за сохранность своего токена. В случае компрометации Пользователь обязан незамедлительно уведомить Администрацию сервиса wantedjson.ru и отозвать скомпрометированный токен.

4.1. Пользователю предоставляется неисключительное, непередаваемое, отзывное право на использование API исключительно для собственных нужд в рамках предоставленных администрацией Сервиса лимитов.

4.2. Разрешённые способы использования:

  • получение данных через эндпоинты API для интеграции в собственные разрабатываемые и тестируемые приложения, веб‑сайты Пользователя. Последний имеет право на доступ к данным Сервиса исключительно в целях обучения, прототипирования и тестирования на период разработки своего сайта, Web-приложения и т.п;
  • кэширование данных сроком не более 24 часов;

4.3. Запрещённые способы использования:

  • продажа, сублицензирование или передача доступа к API третьим лицам;
  • создание сервисов‑зеркал или прокси‑сервисов, дублирующих функциональность API;
  • массовый парсинг или извлечение данных с целью создания собственной базы данных;
  • использование API для рассылки спама, вредоносных действий или атак на другие системы
  • модификация, декомпиляция или реверс‑инжиниринг API
  • использование API в обучающих целях сторонними организациями, юридическими лицами, ВУЗами и другими образовательными учрежденями без получения персональной лицензии от Администрации Сервиса.

4.4. Использование сайта в образовательных целях (в том числе в рамках учебных программ, тренингов, онлайн-курсов и иных образовательных мероприятий) разрешается только после получения персональной лицензии от администрации сервиса. Лицензия выдаётся на основании электронного запроса по указанной ниже электронной почте, в котором должны быть указаны цели использования, перечень материалов сайта, которые планируется использовать, и другие сведения, запрашиваемые администрацией. Порядок выдачи лицензии и её условия определяются администрацией сайта.

5. Технические условия и лимиты

5.1. Базовый URL API: https://api.wantedjson.ru/.

5.2. Формат данных: JSON (заголовок Content-Type: application/json).

5.3. Поддерживаемые методы HTTP: GET, POST, PATCH, DELETE (в зависимости от эндпоинта).

5.4. Лимиты запросов:

  • 100 бесплатных запросов в сутки на один токен (или на одного пользователя);

5.5. При превышении лимитов API возвращает код 429 Too Many Requests!
